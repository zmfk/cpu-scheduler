# 处理机调度算法模拟器

一个基于 HTML / CSS / JavaScript 的 CPU 调度算法可视化模拟器，无需依赖、开箱即用。

## 功能

- 支持 8 种调度算法：FCFS、SJF、SRTF、RR、HRRN、PRIO、PRIO-P、MLFQ
- 逐秒时间轴动画，实时显示就绪队列与运行进程
- 甘特图展示完整调度过程
- 输出每个进程的开始时间、完成时间、周转时间、等待时间与平均值
- 支持任意两种算法横向对比
- 内置经典测试用例，一键自检算法正确性
- 导出 CSV 结果、保存 / 导入进程配置

## 运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

## 使用说明

1. 配置进程：填写进程名、到达时间、运行时间，需要时填写优先级
2. 选择算法：从算法列表中选择一个，RR / MLFQ 需额外指定时间片
3. 点击「开始调度」，逐步查看调度过程与结果

## 规则说明

- **平局规则**：到达时间相同 → 按输入顺序（越靠前优先级越高）
- **优先级**：数值越小优先级越高
- **MLFQ**：三级反馈队列，时间片默认 `[2, 4, 8]`

## 算法自检

点击页面右上角「🧪 算法自检」，程序会运行内置的经典测试用例，并与手算结果比对，用于验证算法实现的正确性。
